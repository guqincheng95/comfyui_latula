# 拉图 0.03 · 通用装配测试版

- 保留一份完整工作流，在运行页点击道具切换模块、勾选组合输出，不再往返装配台或复制多份配置。切换保留参数与本次已选素材。
- 引入通用执行图编译：启用/停用、按端口类型旁路透传、路径开关裁剪、独立输出组合；旁路匹配不明确时阻止提交。
- 节点定义驱动下拉选项、数值范围、图片上传、自定义 IMAGE/MASK 端口；支持平台原生代理只读同步或导入 object_info，普通画布可补充分组与端口信息。
- 多图参考按节点声明端口自动装配，可批量添加；图片连接为真实 LoadImage→IMAGE，不将文件名字符串冒充张量。
- 遮罩画板支持画笔/橡皮、撤销、反选、清空；独立上传黑白 PNG 并接入 MASK 连线，原图 RGB 不被覆盖。最大 2400 万像素。
- 结构化参数里的模型/权重/开关可编辑；已有工作流值与完整服务端选项明确区分，没有定义时不伪造模型库存。
- 旧配置自动升级为运行状态模型，历史快照保持不变。继续使用固定包名、长期签名；versionCode 305。

使用：导入完整 API JSON → 测试连接/读取控件定义 → 保存并装配 → 运行页选择模块 → 多图/提示词/遮罩/下拉参数 → 提交。可先离线导入查看交互，平台生成仍按平台规则使用自己的 API 额度。

边界：API 导出已剔除的节点无法仅靠分组元数据恢复，建议启用所有需要的模块后导出完整 API 图；未知自定义前端脚本不保证自动恢复，按节点类型能力扩展，不为单个工作流重写页面。没有完整服务端定义时，新增参考图端口在提交前会要求先同步/导入定义。平台原生代理当前文档提供标准/Plus 路径，Ultra 规格的完整节点定义请导入对应服务的 object_info。

本版不进行真实平台付费生成，协议和安装检查使用本地模拟服务。最终验证结果完成后补记。
