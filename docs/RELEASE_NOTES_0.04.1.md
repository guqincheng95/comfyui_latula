# 拉图 0.04.1 · 通用操作模块

- 运行页统一为「图片输入、提示词输入、采样设置、图片输出」，不同工作流复用同一套组件。
- 主界面仅显示当前执行路径的关键字段；多图参考与遮罩继续归入图片输入，拆分式种子/采样器/调度节点统一归入采样设置。
- 模型、LoRA、反向提示词、系统模板、辅助参数、输出命名等收进「高级设置」，按原节点分组；展开节点后才加载控件，未修改值沿用原工作流。
- 输出模块直接显示当前功能的任务状态与结果缩略图，可进入详情保存或分享；切换功能不会混入其他输出组合的结果。
- 保留现有功能板块切换、组合输出、旁路、多图/遮罩、参数草稿和原 API 字段绑定。手动显示名称/高级收纳设置在同步定义后保留。
- 包名 com.latula.mobile、长期签名保持一致，versionCode 308，可覆盖更新。

验证范围：29 项核心测试（含未知节点、重新编号、单体/拆分式采样、字段无遗漏/重复、原图绑定、显示设置迁移）；浏览器完整交互和 Android 15 模拟器安装回归均已通过后发布 APK。所有协议测试使用本地模拟服务，没有消耗平台点数或进行真实 GPU 生成。

边界：需服务端节点定义才能获得完整下拉库存、数值约束及新增媒体端口；没有定义时只显示工作流已有值，不伪造选项。未知节点的专用前端脚本仍可能需要按能力扩展。固定噪声曲线等未暴露 steps 的工作流不会凭空增加步数参数。

补充：通用字符串中转节点的采样器/调度器按消费端口归入采样设置，负向提示词中转按节点进入高级设置，保持同类操作位置一致。
