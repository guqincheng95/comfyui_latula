# 拉图 0.01 测试说明

## 版本与定位

用户版本号为 0.01；npm 使用合法语义版本 0.0.1，Android versionName 0.01、versionCode 301。本版是在原仓库中实际实现的第一个像素港湾前端版本，覆盖核心 ComfyUI API 工作流自动装配，而不是此前 0.3.0 的改名准备提交。

主页使用用户确认的月夜三猫方案：前景人物保留，门口女性为小尺寸像素 NPC，三个主题猫窝、石阶和木质牌匾。背景素材与实时文字、按钮、选中反馈分别实现；内部共用木质金边面板、图标、字段模块和操作状态。

## 建议测试顺序

1. 点击进入工作流，未装配时应引导到装配台。
2. 导入自己已跑通的 API JSON，检查图片、提示词与常用数值是否正确装配。
3. 填写真实 ComfyUI 地址并测试，检查模型名、采样器、字段范围和缺失节点提示。
4. 保存装配，回主页检查名称与高亮；关闭重开后应保留选择。
5. 上传小尺寸素材，提交一次真实任务，查看任务编号、排队和结果。
6. 生成期间返回主页或切换装配，旧任务不能改变来源或重复提交。
7. 到图鉴预览、收藏、保存文件，并使用相同参数回到草稿；复用动作不应自动创建任务。
8. 清理预览/分享缓存后，任务记录仍应存在。
9. 检查不同文字长度、触感/减少动态效果、系统返回键和分享面板。

## 验证边界

- 本地 8 项解析/装配/字段回写/输出及输入校验测试已通过，前端 production build 与后端 Python 编译通过。
- 受限本地执行环境无法启动浏览器，完整浏览器协议回归和 APK 构建移至 GitHub Actions；最终结果以构建记录与后续日志为准。
- 协议回归使用明确标识的模拟 ComfyUI 服务和测试图，不调用 GPU，不代表真实模型生成实测。
- 没有连接用户电脑或调用付费平台；用户真实工作流、手机 WebView 上传、视频兼容与系统文件分享需进行真机试用。
- 首版不包含手机节点连线编辑、复杂遮罩编辑或任意平台接口的通用适配。
- 当前保存结果通过系统面板选择目标；不宣称已经直接写入系统照片相册。
