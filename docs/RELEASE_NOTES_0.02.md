# 拉图 0.02 · RunningHub 测试版

- 增加 RunningHub 工作流入口，支持完整网页链接或字符串工作流 ID。
- 可读取平台 API JSON，也可手动导入；复用通用素材、提示词、数值与开关模块。
- 整合工作流必须选择一个输出分支；按依赖裁剪并提交完整 JSON，避免无意执行独立分支。可命名分支，复制配置保存多个模式。
- 接入官方媒体上传、创建任务、V2 结果查询和历史图鉴；固定种子显式传参，创建请求失败不自动重试。
- 增加 LoadImageGoohai 图片输入；预览缓存文本不再作为提示词输入，系统/固定提示词收进高级参数。
- 安卓 API Key 使用 Android Keystore 加密保存，与工作流及历史记录分离，可在设置清除；网页预览仅保留本次会话。
- 继续使用夜景三猫界面、com.latula.mobile 和固定长期证书。versionCode 304，可覆盖安装同签名 0.01.1。

使用：装配工作流 → 接入 RunningHub → 粘贴链接 → 填写 API Key → 读取云端工作流 → 选择/命名输出分支 → 保存并装配 → 上传素材并提交。

验证范围：核心协议测试、浏览器模拟接口和 Android 模拟器安装检查使用隔离的本地模拟服务。没有调用用户平台密钥或付费 GPU，真实平台权限、模型/节点兼容及手机文件选择/下载分享需实际试用。遮罩绘制、AI 应用 webappId、RunningHub 取消/余额暂未适配。

验收：16 项核心测试、浏览器完整流程（含图片解码和连续点击防重复）、Android 15 模拟器安装/原生网络/历史恢复/密钥密文与冷启动解密均通过。构建与发布：[43691487205](https://github.com/guqincheng95/comfyui_latula/actions/runs/43691487205)。
