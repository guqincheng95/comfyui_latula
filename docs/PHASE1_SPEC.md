# 拉图第一阶段功能与交互规格

更新：2026-11-15。状态：需求与实施建议，尚未实现本规格中的新首页、装配管理和历史图鉴。原 Runway 模块继续保留。

## 1. 已确认的方向

用户本轮提供 1000110077.png 作为主页视觉基准，画面为夜间像素港湾：蓝色月光、暖色灯光、石板路、工坊、传送门、木质金属包边牌匾、像素人物和远景海港。

主页只有三个主要功能区域：装配工作流、进入工作流、历史任务。底部保留关于、更新、设置、退出等辅助入口。选定装配后有边缘高亮；进入工作流直接打开当前装配的工作流操作页；历史任务以图鉴形式查看已生成图片与视频。

以下标为建议的内容为按上述目标推导出的第一阶段默认方案，可随试用调整，不视为用户已逐项确认。APK 仍只负责前端和任务/结果管理，生成由外部服务执行。

## 2. 主页布局与视觉

| 区域 | 展示与用途 | 主要交互 |
| --- | --- | --- |
| 顶部标题 | 拉图品牌；场景保持参考图夜间氛围 | 第一阶段不增加复杂导航 |
| 装配工作流 | 工坊/齿轮牌匾；辅助信息显示当前工作流短名称 | 点击打开装配管理；装配选定后边缘高亮 |
| 进入工作流 | 传送门/发光书本道具与主牌匾 | 点击进入当前装配工作流的操作页 |
| 历史任务 | 图鉴/书册/告示牌；可附运行中数量与新结果标记 | 点击打开任务与作品图鉴 |
| 底部 | 关于、更新、设置、退出 | 打开对应轻量页面或执行退出逻辑 |

整体沿用像素美术和具有立体结构的方向光。像素场景、人物、牌匾保留复古纹理，文字使用实时渲染的清晰中文，光照层次遵循参考图的冷暖关系。背景、牌匾、道具、文字、高亮与触控热区分别组织，适配不同长宽比和安全区，避免裁掉主入口与底栏。

主入口以可互动的场景道具和牌匾呈现。功能名称保持直白，装饰文案可有游戏氛围；重要状态仍用「未装配、连接异常、排队中、生成中、已完成」等易懂表达。

建议首页只加少量灯火、水面、传送门等局部动效。像素角色第一阶段作为场景装饰；点击入口立即响应，不要求角色先走到地点。白天场景、动态昼夜与复杂镜头留待后续。

## 3. 装配工作流

### 3.1 配置、选中与装配的含义

- 配置：保存一个可使用的工作流入口及其来源、输入字段与默认参数。
- 选中：在列表中预选一个配置，选中项出现边缘高亮。
- 装配：将选中配置设为主页当前工作流，保存后回到主页，其名称与装配标记持续可见。

装配不是在 APK 内编辑节点连线或加载生成模型，也不会提交生成任务。第一阶段建议一次装配一个工作流，允许保存多个配置并随时切换。

### 3.2 列表与配置内容（建议）

每个工作流展示名称、图标/小封面、图片或视频类型、执行来源、连接状态，以及「已装配」标记。提供新增、编辑、复制配置、装配、移除本地配置。移除操作只针对拉图内配置，不默认删除远程工作流或历史结果。

配置中区分：

| 来源 | 配置依据 | 第一阶段处理方式 |
| --- | --- | --- |
| 本地/自建云 ComfyUI | 可达的服务地址、API 格式工作流、字段映射 | 使用已验证模板或明确映射，缺少字段时提示补齐 |
| RunningHub AI 应用 | webappId、平台开放字段、已配置的鉴权链路 | 依平台应用字段生成操作表单 |
| RunningHub 工作流 | workflowId、节点参数映射 | 单独适配，不能与 AI 应用 ID 混用 |
| 已有 Runway 模块 | 原后端地址与固定模块配置 | 保留原调用链，逐步纳入统一入口 |

来源多样性属于总体架构；第一阶段可先交付已真实跑通的一类来源和选定模板，其余标明尚未接入，不把通用输入框当作已完成所有平台适配。

工作流操作表单所需字段包括类型、名称、必填、范围、默认值、可选项、上传限制和接口映射。普通使用者看中文字段，节点 ID 等留在配置的高级部分。

### 3.3 装配和连通状态分开表达

| 状态 | 首页反馈 | 点击进入后的行为 |
| --- | --- | --- |
| 未装配 | 齿轮区域给轻量提示，主入口说明需要先装配 | 引导到装配管理，不停留在无解释的禁用状态 |
| 已装配、待检查 | 显示已选名称与选中边缘，连接状态单独标明 | 可以打开表单，提交前检查必需配置 |
| 已装配、连接正常 | 装配边缘高亮，传送门可有轻微呼吸光 | 直接打开操作页，准备素材和参数 |
| 已装配、连接异常 | 保留选择与装配高亮，小状态灯/文字说明异常 | 允许进入、保留草稿，提交处提供重试或修改连接入口 |

高亮首先表达用户选中了什么，不把断网显示成用户没有装配。App 重开恢复装配选择，并更新连接状态。

## 4. 进入工作流：操作页

点击首页入口进入已装配配置的操作页，不再要求重新选择同一个工作流，也不自动提交任务。

建议页面包括：工作流名称与服务状态、参考图/视频素材区、提示词、常用参数、折叠的高级参数、提交按钮、当前任务与结果区域。

- 输入按当前模板显示：不需要视频的模板不显示视频字段，不支持提示词的模板不强加无效输入。
- 素材选择后先预览，并显示必要的尺寸/时长/大小与限制；支持替换、清除和图片多选（仅模板支持时）。
- 常用参数如比例、种子、数量按模板实际能力开放；第一阶段不要求暴露所有节点。
- 输入错误就地提示，失败后保留已填内容；不同工作流的草稿分别保存。素材引用失效时明确要求重选。
- 提交前明确服务来源、当前参数和必需素材；费用仅在接口能可靠提供时展示，不虚构额度或预估。
- 提交按钮说明真实动作，提交中防止连点；已创建的任务编号先保存，再开始状态查询。
- 上传、平台接收、排队、运行、完成、失败分阶段反馈。未知整体进度时展示阶段与耗时，不制作假百分比。
- 成功后在操作页查看结果，同时进入历史图鉴；支持预览、保存到手机、打开详情和再次使用参数。

若用户在任务生成时切换装配，旧任务仍绑定提交时的工作流配置版本、来源、服务地址与参数快照。新装配不应重写旧任务或将旧结果归给新工作流。

## 5. 历史任务：作品图鉴

### 5.1 图鉴首页（建议）

采用像素相册/图鉴外观，内容仍为实际结果缩略图。默认按提交时间从新到旧，图片显示预览缩略图，视频优先取可用封面或第一帧，并显示播放标记与时长（可获取时）。不为封面把整段视频预载入内存。

建议在同一图鉴内区分「作品」与「进行中/失败任务」：已完成结果方便浏览，运行中的任务仍容易找到，不要求用户再学习一个独立主入口。空图鉴提供前往装配或开始使用的引导。

第一阶段优先支持图片/视频筛选、任务状态、收藏标记与按工作流筛选；复杂搜索、任意排序和批量管理可后续增加。

### 5.2 作品与任务详情

展示大图或视频播放器，以及工作流名称、执行来源、提交时间、状态、提示词和公开可用的参数；一任务多结果归在同一任务下，可逐个翻看。钥匙、临时签名地址等不作为可见参数或导出内容。

| 动作 | 默认行为 |
| --- | --- |
| 保存/再次下载 | 获取原始结果文件；缩略图只用于预览 |
| 收藏 | 修改图鉴标记，不复制一份大文件 |
| 使用相同参数 | 从任务快照创建操作页草稿，等待用户明确提交，不自动再生成 |
| 用作新素材 | 支持时带入当前或指定工作流输入；跨服务必要时重新上传 |
| 查看失败原因 | 说明失败阶段，并保留参数和可重用素材 |
| 移除记录/清理文件 | 区分历史记录、预览缓存、下载副本和远端结果，说明删除范围 |

历史元数据、缩略图缓存、原图/视频下载文件分别管理。清理下载副本不自动删除任务记录；远程链接失效时保留记录和可用缩略图，显示「原文件暂不可用」，不能把预览图当原图下载。结果是否需要长期保留由用户选择保存/归档，不能仅依靠平台临时 URL 承诺永久图鉴。

## 6. 底部辅助入口

| 入口 | 第一阶段建议功能 |
| --- | --- |
| 关于 | 拉图的产品说明、当前版本、项目说明/开源声明，以及「生成由连接服务完成」的清楚说明 |
| 更新 | 当前版本、更新记录、检查更新；如尚无真实更新源则显示未配置，不显示假的「已是最新」；发现新版后由用户主动安装 |
| 设置 | 动效强度/减少动态效果、可选音效与触感、预览/下载设置、缓存占用与清理；音效默认关闭 |
| 退出 | 离开拉图界面；已被服务接收的任务继续在外部执行，返回后恢复查询；上传或提交尚未完成时说明可能中断 |

工作流来源、字段映射与该服务的配置放在装配管理中；底部设置主要处理全局使用偏好与存储，避免两处维护同一套相互冲突的配置。底部可附一个很轻的连接/运行中提示，不再增加第四个大区域。

退出应用、取消任务、删除结果是三种不同动作；退出不默认取消服务器任务。取消仅在来源支持且能准确定位该任务时提供。

## 7. 第一阶段动效

- 装配入口：按压、齿轮短转；完成装配后边缘高亮保持，短名称更新。
- 进入入口：按压后传送门或书本道具响应，页面短暂过渡；立即接续操作，不播放冗长开场。
- 图鉴入口：书页/告示牌局部反馈，进入作品列表；新结果可显示角标，由查看后清除。
- 底栏：每个小道具的按下/松开与选中状态统一。
- 首页环境动效与业务状态分层；进入后台暂停装饰动画，返回时先查询实际任务。

具体时长、触控热区与减少动态效果遵循 UI_DESIGN_PLAN.md。动效既保留游戏氛围，也不能挡住文字、缩小可点范围、拖慢导航或造成重复提交。

## 8. 范围与顺序

第一阶段必须形成：主页 → 装配并记住选择 → 进入当前工作流 → 提交真实任务 → 查看结果 → 历史图鉴回看/复用的完整闭环，并完善底部辅助入口与必要状态。

建议实施顺序：

1. 三入口路由、装配配置/状态和任务/历史数据结构。
2. 沿用已有模块或选定来源完成一个可验证的真实任务链路。
3. 将参考图转化为可适配的像素场景与独立 UI 元素，连通三个真实入口。
4. 增加历史缩略图、预览/保存、参数复用、收藏及结果失效处理。
5. 完善底栏、局部动效和不同屏幕/前后台状态。

暂留后续：手机节点连线编辑器、任意工作流全自动适配、多个完整昼夜场景、角色自由移动、账号商城/积分成就和大规模商业调度。这些不作为第一阶段验收的前置条件。

## 9. 验收场景

- 首次打开未装配时，可从主页清楚找到配置入口；点进入也能到达装配引导。
- 新增两个有效配置，切换装配后边缘高亮、名称与进入页面同步；重开 App 仍是上次装配。
- 已装配后断网，选择和草稿保留，异常与重试位置明确；恢复后可以继续。
- 点进入只打开表单，点提交才创建任务；重复点击不重复创建。
- 生成中返回首页、切换工作流、离开并返回，原任务仍按原来源恢复和归档。
- 图片和视频任务完成后均可在图鉴找到，能预览、保存和查看参数；多结果不丢失。
- 参数复用只准备草稿，不在后台自动再次提交；缺失素材有明确提示。
- 下载副本删除或远程结果失效，历史记录的剩余内容和文件可用状态表达准确。
- 关于/更新/设置/退出有实际行为或明确未配置状态；退出不误取消远程任务。
- 小屏和长屏下三个主入口与底栏可用，实时文字清晰，减少动态效果模式正常。
